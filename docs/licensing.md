# Licenciamento em revisão / Licensing pending

Nenhuma licença nova foi concedida nesta preparação. Apache-2.0 foi sugerida para o
código próprio, mas depende de aprovação do titular. O inventário de arquivos da origem
e a pesquisa histórica por LICENSE, COPYING e NOTICE não localizaram uma licença para
o núcleo. Isso não prova titularidade nem autoriza relicenciar contribuições de terceiros.

Autores humanos, committers e datas foram preservados na seleção. Por solicitação
do dono em 2026-10-27, as mensagens foram padronizadas e as coautorias de provedor
de IA foram removidas do histórico público, sem alterar o conteúdo dos commits.
Antes de uma release licenciada: confirmar direitos sobre código e contribuições; escolher licença
do código; definir separadamente a dos elementos próprios da organização do dataset;
incluir os avisos exigidos e revisar as dependências na distribuição efetivamente feita.
A abertura do PR público foi autorizada separadamente pelo dono. Isso não aprova a
proposta Apache-2.0 nem define uma licença para os elementos próprios do dataset.

## Textos oficiais e elementos próprios

A [Lei 9.610/1998](https://www.planalto.gov.br/ccivil_03/leis/l9610.htm), art. 8º, IV,
exclui textos de leis e outros atos oficiais da proteção autoral nela prevista. O art.
7º, XIII e §2º distingue a organização protegível de bases de dados dos dados em si.
O projeto não reivindica propriedade sobre leis. Código, documentação, seleção,
curadoria, organização e possíveis elementos de terceiros precisam ser tratados
separadamente. Não presumir que todos os elementos visuais/scripts de uma página HTML
tenham o mesmo regime do texto legal; os HTMLs são fixtures de evidência, não código
redistribuído para execução.
